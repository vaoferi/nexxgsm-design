Dell BIOS Password Types & Recovery Guide

Identify your Dell BIOS password prompt and follow the correct recovery path — whether you're locked out of Setup, startup, or your drive.

  2. System / Power-On Password

Admin or Setup Password

An Admin or Setup password protects firmware settings inside F2 BIOS Setup. You can still start Windows, but settings like boot order, Secure Boot, or virtualization are locked until you enter the correct password.

Pro tip: If Windows starts normally but F2 asks for a password, you have an Admin lock — not a System lock.

System or Power-On Password

A System password is checked before the operating system starts. The laptop won't boot without it. This is separate from a Windows password, PIN, or Microsoft account.

  • Appears at power-on, before Dell logo or with a lock icon
  • Blocks all access to BIOS and boot menu (F12)
  • Requires Dell service-tag-matched unlock code

HDD or SSD Password

A drive password protects the storage device itself — not Windows, not BIOS. Dell cannot create password release codes for NVMe SSDs. For SATA HDD/SSD, a master drive password may work.

Windows Sign-in & BitLocker Are Separate

A Windows password or PIN controls OS sign-in. BitLocker encrypts the volume and asks for a 48-digit recovery key. Neither credential is a Dell System, Admin, or HDD password.

What Information to Collect

  • Exact wording of the prompt
  • When it appears: at power-on, only in F2, or naming a drive
  • Full error code or system code (including suffix after dash)
  • Service Tag for device identification
